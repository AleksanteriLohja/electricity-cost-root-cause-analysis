# electricity-cost-root-cause-analysis
Why did the electricity bill rise when the average price fell?  Root-cause analysis of consumption-weighted vs. simple average spot prices (Finland, 2024–2025).


## Data sources & licensing

- Consumption data: Fingrid open data (CC 4.0 BY) — https://data.fingrid.fi/
- Spot prices: sahkotin.fi (Pakastin Oy), price data owned by Nord Pool.
